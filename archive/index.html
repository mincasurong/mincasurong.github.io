RESEARCH (~2022) · KFDA MEDICAL EXOSKELETON (6 HOSPITALS) & AI THERAPIST

Gait Rehabilitation Exoskeletons (SUBAR) & Clinical AI Therapist

During my B.S. (2016), M.S. (2018), and Ph.D. (2022) in Mechanical Engineering at Sogang University, I engineered mechanical actuators, assist-as-needed adaptive impedance controllers, and clinical machine-learning software for lower-limb gait rehabilitation exoskeletons. Our team earned medical device certification from the Korea Food and Drug Administration (KFDA) and deployed the SUBAR exoskeleton across 6 clinical hospitals in Korea. Across three years of hospital trials with stroke patients and physical therapists, I collected multi-sensor human-robot interaction telemetry to train and deploy the clinical AI Therapist (IEEE TNSRE 2019, 2020; IEEE BioRob 2020).

Engineering Stack (2015–2022): Nonlinear and adaptive impedance control, machine learning (ANFIS, PSO, reinforcement learning), physical human-robot interaction (HRI), mechanical CAD (Siemens NX, SolidWorks), OpenSim musculoskeletal modeling, and real-time software in C/C++, Python, MATLAB/Simulink, LabVIEW, and ROS.

TECHNICAL RECAP · GOOGLE CLOUD ONBOARD: GOOGLE SKILLS EDITION (WESTIN JOSUN PARNAS)

Scaling Multi-Agent Services on Vertex AI · Google Cloud OnBoard Notes

Engineering notes from Google Cloud OnBoard: Google Skills Edition (Westin Josun Parnas, Seoul), documenting the architectural transition from single-session hackathon prototypes (GeminiSpace) to stateful multi-agent production runtimes (Gouncil and m9g-agent-corps).

1. Multimodal Model Routing in Vertex AI Model Garden

Technical sessions led by Google Cloud and Google DeepMind engineers covered unified serving across 200+ managed endpoints in Vertex AI Model Garden, pairing Gemini 3 and open-weight Gemma 3 models with GenMedia pipelines (Veo video generation and Lyria audio synthesis) under centralized quota and latency telemetry.

2. Track 1: Agent Development Kit (ADK), MCP vs. A2A & Cloud Run

Protocol Separation (MCP vs. A2A): The Model Context Protocol (MCP) binds an individual agent to deterministic tools, databases, and REST APIs, whereas the Agent2Agent (A2A) protocol coordinates asynchronous task handoffs and capability discovery across separate autonomous agents. Separating tool execution (MCP) from peer delegation (A2A) directly shaped the routing layer in Gouncil.
Stateless Compute on Cloud Run: Deploying LangGraph and ADK workers as autoscaling containers on Cloud Run backed by AlloyDB or Cloud SQL vector indexes and Cloud Build CI/CD pipelines isolates bursty agent inference from persistent state.

3. Four-Layer Vertex AI Memory Architecture

Generative AI Field Solution Architect Sang-woon So detailed a four-tier memory partition that bounds prompt token growth across long-horizon multi-turn sessions:

Memory LayerCognitive Role & Vertex AI Implementation
1. Session Memory (Short-Term)Stores active turn state, intermediate reasoning traces, and tool return payloads within a live session.
2. Personalized Memory Bank (Long-Term)Persists structured user preferences, recurring constraints, and cross-session summaries across interactions.
3. External Information GroundingQueries live web facts and geospatial state through Google Search and Google Maps grounding.
4. Internal Information RetrievalRetrieves private domain documents via Vertex AI RAG Engine and ScaNN approximate nearest-neighbor vector search.
