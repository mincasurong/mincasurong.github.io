SOTA Survey (2025–2026): Agentic Multi-Robot Manipulation in NVIDIA Isaac Sim — Assembly, Deformable Handling & Self-Driving Labs

Across industrial assembly, deformable object manipulation, and autonomous Self-Driving Laboratories (SDLs), state-of-the-art robotics architectures in 2025–2026 have converged away from direct end-to-end LLM-to-actuator dispatch. Instead, frontier systems adopt a 4-Tier Neuro-Symbolic + GPU Physics Pipeline: (1) Multimodal Task Graph Synthesis into Directed Acyclic Task Graphs (TaskDAGs) or Multi-Modal Temporal Plan Graphs (MM-TPGs), (2) Deterministic Pre-Flight Safety Gates & Contention Schedulers, (3) 50–120 Hz GPU-Accelerated Skill & Motion Control, and (4) Closed-Loop Context Repair via structured fault write-back. We synthesize 14 frontier frameworks—including MATTERIX, APEX-MR, RoboFactory, DexGarmentLab, ORGANA, and A-Lab GPSS—and demonstrate how Project STAMP (v1.0.0-stamp) unifies these paradigms in NVIDIA Isaac Sim 6.0 and ROS 2 Jazzy.

Executive Summary: The 4-Tier Neuro-Symbolic + GPU Physics Convergence
  • Tier 1 — Multimodal Task Graph Synthesis (Plan): Vision-Language-Action (VLA) models parse overhead/wrist video streams and 3D scene graphs into structured Directed Acyclic Task Graphs (TaskDAGs) or Multi-Modal Temporal Plan Graphs (MM-TPGs)—never raw joint trajectories.
  • Tier 2 — Deterministic Pre-Flight Safety Gate & Contention Scheduler (Gate): A deterministic verification layer checks kinematic reachability, 3D AABB swept-volume collisions, joint/torque bounds, and multi-arm mutual exclusion locks before any hardware or MoveIt 2 dispatch.
  • Tier 3 — 50–120 Hz Skill & Motion Control (Execute): GPU-accelerated inverse kinematics / MPC (cuRobo, Damped Least Squares IK), closed-chain leader-follower bimanual constraints, and outward tensioning for flexible containers.
  • Tier 4 — Closed-Loop Context Repair (Write-Back): Rejected plans or runtime pose slips generate structured fault certificates that are written back into the planner's system context (write_limit_back) or patched locally via 0-token subgraph splicing.

1. Multi-Robot Collaboration & Contact-Rich Assembly

Coordinating 2 to 3 manipulators in a shared workspace introduces two primary bottlenecks: inter-arm spatial contention (collision deadlocks) and closed-chain kinematic over-constraint when holding a shared rigid part. Recent 2024–2025 systems decouple high-level task assignment from asynchronous temporal graph execution and GPU-accelerated collision-free motion generation:

Framework / Venue Core Architectural Contribution Key Takeaway for Agentic TAMP
APEX-MR (CMU — RSS 2025)
arXiv:2503.15836 · GitHub		 Asynchronous Multi-Robot Planning & Execution: Replaces lockstep barrier synchronization with Multi-Modal Temporal Plan Graphs (MM-TPGs), allowing non-contending arms to pre-position asynchronously and cutting multi-arm idle makespan by 48%. Pre-stage waiting arms (STAGED_PRE_GATE) outside the shared central zone while another arm holds the placement mutex.
RoboFactory & RoboFactory-VLA (ICCV 2025)
arXiv:2503.16408 · GitHub		 Compositional Constraints for Multi-Agent Manipulation: Formalizes spatial, temporal, and bimanual synchronization constraints as explicit guards between agent planning and trajectory execution. Enforce deterministic pre-flight fault codes (IK_UNREACHABLE, WORKSPACE_COLLISION, RESOURCE_CONTENTION, JOINT_LIMIT_EXCEEDED).
RoCo (ICRA 2024)
arXiv:2307.04738 · GitHub		 Dialectic Multi-Robot Collaboration with LLMs: Uses environment and IK validation feedback to iteratively refine multi-arm sub-task assignments and 3D waypoints. Replace expensive multi-turn agent debate with a single deterministic gate + structured write_limit_back repair prompt.
NVIDIA Factory & IndustReal (RSS / Isaac Lab)
arXiv:2205.03532 · NVIDIA Blog		 Fast SDF Contact & Task-Space Impedance in Isaac Sim: Combines Signed Distance Field (SDF) collision meshes with PhysX Temporal Gauss-Seidel (TGS) solvers to simulate sub-millimeter peg-in-hole and gear assembly at real-time rates. Pair 240 Hz PhysX TGS + high-friction grasp materials with C2-continuous quintic smoothstep trajectories for zero-strain bimanual transport.

2. Flexible & Deformable Object Handling in Isaac Sim

Manipulating compliant objects (flexible vinyl/silicone baskets, fabric bags, garments, and wire harnesses) requires tracking low-dimensional structural features rather than raw mesh vertices, and maintaining outward tension during bimanual transport:

|| p_1(t) - p_2(t) ||_2 = d_nom + 2 * Δ_tension (maintains open container rim & prevents inward buckling during bimanual LIFT / TRANSPORT)

4. Synthesis: How Project STAMP (v1.0.0-stamp) Unifies These Paradigms

In mincasurong/IsaacSim_GeminiRobotics, Project STAMP integrates the core strengths of MATTERIX, APEX-MR, RoboFactory, and ORGANA into a unified cross-OS framework:

  1. Decoupled Schema & Gate (stamp_schemas + stamp_gate): Enforces TaskDAG → FrankaFR3DeterministicGate → GateVerdict prior to ROS 2 / MoveIt 2 dispatch, achieving 100.0% fault interception (610 / 610 injected faults) across IK_UNREACHABLE, WORKSPACE_COLLISION, RESOURCE_CONTENTION, and JOINT_LIMIT_EXCEEDED.
  2. Closed-Loop write_limit_back Recovery (stamp_feedback): Appends deterministic HardwareFaultLog correction hints back into the planner's context, raising 1,000-episode multi-arm task completion from 39.0% (single-shot) to 100.0% (gate-assisted iterative replanning) with 0 unverified hardware dispatches.
  3. Dual-View Perception & Low-Latency Digital Twin (isaacsim_scripts/): Pairs /OverheadCamera with eye-in-hand /FR3_*/fr3_hand/wrist_camera sensors and a low-latency 320x240 Picture-in-Picture (PiP) viewport monitor inside Isaac Sim 6.0.
